# 操作手册：高中语文知识卡（样例：借景抒情）

对应验收样例：[input-output.md](input-output.md) #3。本手册说明如何用
`knowledge-concept-card` 生成一张语文概念知识卡，并核对输出质量。

## 适用场景

- 文言虚词、表现手法、阅读方法、论证结构、古诗词手法、写作方法
- 高一至高三复习，古诗鉴赏与阅读理解专项
- 需要“真实原文 + 注释 + 结构分析 + 答题句式”的概念卡

## 输入方式

结构化调用（推荐）：

```text
subject: high-school-chinese
concept: 借景抒情
level: 高一
focus: 古诗鉴赏答题
format: card
```

自然语言同样有效：

```text
给我做一张高一语文“借景抒情”的知识卡，用《天净沙·秋思》举例。
```

## 操作步骤

1. 确认 `subject: high-school-chinese`。
2. 提供 `concept`（必填）：一个术语、手法或题型。
3. 可选 `level`（如 `高一`）与 `focus`（答题、鉴赏、写作应用）。
4. 需要举例时，在输入中指定可靠篇目（如《天净沙·秋思》）；未指定时
   skill 会选取有据可查的原文。
5. 核对引文、作者、标点与教材一致，再用于课堂。

## 期望输出与验收

| 验收点 | 通过标准 |
| --- | --- |
| 定义 | 术语定义精确，必要时与易混手法辨析（直抒胸臆、托物言志） |
| 原文 | 真实、可靠、标点正确，注明作者与篇名；禁止编造引文 |
| 注释 | 关键字词有注音/释义，语法或修辞有说明 |
| 结构分析 | 说明句子/段落/全诗如何起作用，不空泛贴“生动形象”标签 |
| 关系图 | 景物 → 意境 → 情感的关系映射，指向具体词句证据 |
| 答题句式 | 提供可套用的规范作答框架，落地到具体文本 |
| 排版 | 原文、注释、答题句式为排字文本，插图内不放原文 |

## 常见问题

- **引文可靠性**：任何原文必须可溯源；拿不准时要求换篇目，不要接受编造。
- **“借景抒情” vs “托物言志”**：前者借景抒“情”，后者借物言“志”（志向品格），
  卡片应给出区分。
- **鉴赏空泛**：验收时拒绝“生动形象地写出了……”这类无证据结论，必须落到
  具体词句。
