# 操作手册：高中数学知识卡（样例：二次函数图像平移）

对应验收样例：[input-output.md](input-output.md) #4。本手册说明如何用
`knowledge-concept-card` 生成一张数学知识点知识卡，并核对输出质量。

## 适用场景

- 单个知识点、定理、公式、题型或常见错误
- 高一至高三复习，函数、几何、统计等模块
- 需要“公式 + 图像对比 + 例题 + 易错警示”的知识卡

## 输入方式

结构化调用（推荐）：

```text
subject: high-school-math
concept: 二次函数图像平移
level: 高一
focus: 顶点式与符号陷阱
format: card-and-html
```

自然语言同样有效：

```text
给我做一张高一数学“二次函数图像平移”的教材知识卡，附可编辑 HTML。
```

## 操作步骤

1. 确认 `subject: high-school-math`。
2. 提供 `concept`（必填）：一个知识点或题型，不要跨多个主题。
3. 可选 `level`（如 `高一`）与 `focus`（考点、易错点）。
4. 公式与图像密集，建议 `card-and-html` 或 `card`（配确定性排版）。
5. 核对公式符号、参数条件、例题计算，再用于教学。

## 期望输出与验收

| 验收点 | 通过标准 |
| --- | --- |
| 公式 | 顶点式 `y = a(x − h)² + k` 正确，含 a ≠ 0 等条件 |
| 参数说明 | a（开口/形状）、h（左右）、k（上下）方向与符号正确 |
| 图像 | 母函数与变换后图像对比，顶点与平移量标注清楚 |
| 例题 | 一个完整例题：顶点定位、方向判断、结果 |
| 易错警示 | 指出 `(x − h)` 内符号易反（“减号向右”），配自检口诀 |
| 排版 | 公式、表格、坐标标签为确定性排版（HTML/CSS/SVG） |

## 常见问题

- **符号陷阱**：`y = (x + 3)²` 是向左而非向右，卡片必须显式警示。
- **图像精度**：对比图只需示意顶点与形状关系，不必逐点精确；关键标注
  （顶点坐标、平移箭头）必须正确。
- **一个知识点一张卡**：平移与翻折、伸缩不要混在一张卡里，避免教学单元
  过大。
