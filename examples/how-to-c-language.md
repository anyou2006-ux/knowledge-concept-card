# 操作手册：C 语言知识卡（样例：pointer dereference）

对应验收样例：[input-output.md](input-output.md) #2。本手册说明如何用
`knowledge-concept-card` 生成一张 C 语言概念知识卡，并核对输出质量。

## 适用场景

- 单个语法、关键字、数据类型、库函数、内存概念、编译行为、算法
- 入门教学（指针、数组、生命周期）与考前复习
- 需要“最小可编译代码 + 内存/执行模型图”的概念卡

## 输入方式

结构化调用（推荐）：

```text
subject: c-language
concept: pointer dereference
level: beginner
focus: NULL 与悬垂指针的未定义行为
format: card-and-html
```

自然语言同样有效：

```text
给我做一张 C 语言入门知识卡，讲清楚 *ptr 解引用，附可编辑 HTML。
```

## 操作步骤

1. 确认 `subject: c-language`，避免与泛编程术语混淆。
2. 提供 `concept`（必填）：一个概念或语法项，一次一个。
3. 可选 `level`（如 `beginner`、`intermediate`）与 `focus`（易错点、考点）。
4. 选择 `format`：代码与内存图密集，建议直接 `card-and-html`。
5. 核对代码可编译、输出正确、UB 表述不夸大，再用于教学。

## 期望输出与验收

| 验收点 | 通过标准 |
| --- | --- |
| 定义 | 精确，且区分语言保证 / 常见编译器行为 / 平台行为 |
| 语法签名 | 最小可编译代码，非伪代码 |
| 逐行解释 | 非显然行为有逐行说明（如 `*p = 10` 修改的是 n） |
| 输出/状态 | 明确期望输出或状态变化，含前置条件 |
| 模型图 | 内存图展示地址、值、指针箭头，粒度与概念匹配 |
| 陷阱 | 一个真实错误或 UB：NULL / 悬垂指针解引用 |
| 对比 | 必要时与邻近概念对比（如 `p` 与 `*p`） |

## 常见问题

- **未定义行为**：卡片必须如实说明“不保证任何特定结果”，不得给出确定的
  崩溃/报错承诺。
- **代码可运行性**：产出代码应可直接编译运行；如无法运行，须明确说明。
- **粒度**：概念卡只讲一个最小教学单元（如“解引用”），不要扩成指针专题。
