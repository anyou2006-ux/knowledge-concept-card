# Acceptance Examples\n\nThese examples define scope and quality, not the full rendered card. A passing\nresult covers the expected points, keeps facts internally consistent, and uses a\nvisual that explains the difficult relationship rather than merely decorating\nthe page.\n\n## 1. English Vocabulary\n\n**Input**\n\n```text\nsubject: english-vocabulary\nconcept: resilience\nlevel: senior-high\nformat: content-spec\n```\n\n**Expected coverage**\n\n- UK/US IPA, noun label, Chinese and English definitions\n- a natural sentence about recovering after difficulty\n- collocations such as `emotional resilience` and `build resilience`\n- no forced antonym if none is genuinely direct\n- an illustration of a bent young plant returning upright after wind, with the\n  growth/recovery relationship visible\n- a rendering brief that keeps IPA and the example sentence as typeset text\n\n## 2. C Language\n\n**Input**\n\n```text\nsubject: c-language\nconcept: pointer dereference\nlevel: beginner\nformat: card-and-html\n```\n\n**Expected coverage**\n\n- `*ptr` syntax and the precondition that `ptr` points to a valid object\n- a minimal program that changes an integer through a pointer\n- a diagram connecting `ptr`, an address, and the object value\n- a warning that dereferencing `NULL` or a dangling pointer is undefined behavior\n- a self-contained HTML artifact instead of an image-only response\n\n## 3. High-School Chinese\n\n**Input**\n\n```text\nsubject: high-school-chinese\nconcept: 借景抒情\nlevel: 高一\nformat: card\n```\n\n**Expected coverage**\n\n- a precise definition of the technique\n- a verified excerpt selected for clear evidence, with annotation\n- an image relationship map: scene details -> emotional atmosphere -> feeling\n- an exam response sentence frame grounded in the quoted details\n- original text and annotations retained as typeset text\n\n## 4. High-School Mathematics\n\n**Input**\n\n```text\nsubject: high-school-math\nconcept: 二次函数图像平移\nlevel: 高一\nformat: card-and-html\n```\n\n**Expected coverage**\n\n- `y = a(x - h)^2 + k` and conditions on `a`, `h`, and `k`\n- a coordinate graph contrasting the parent parabola with its translated form\n- a short worked example identifying vertex and direction\n- a warning that the sign inside `(x - h)` is easy to reverse\n- a deterministic text layout for formulae and labels\n\n## Manual Review Checklist\n\nFor every new profile or substantial rule change, review at least one realistic\nresult with these questions:\n\n1. Does the title promise one teachable learning outcome?\n2. Are definitions, formulas, code behavior, citations, and examples accurate?\n3. Are all conditions, source constraints, and caveats visible where needed?\n4. Does the visual explain a relationship that prose alone leaves difficult?\n5. Is dense text reserved for the deterministic layout layer?\n
